# About these screenshots

These application screenshots were supplied by the project owner for publication on 18 October 2026. They are the original PNG files, copied without editing from the project's Screenshot folder.

`AbeSweep01.png` shows the scan results and cleanup selection. `Abesweep04.png` shows the home screen after the quarantine has been permanently deleted, with the log retained. The settings, item counts and access status reflect that Mac, rather than the defaults of a new installation.

The exact build used for the captures was not recorded. The images show the interface; build and test results are documented separately. Neither image shows a personal home-directory path, detailed log, desktop or screen-sharing controls.
